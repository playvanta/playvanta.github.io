How to Import Your Crosshair into Valorant

  1. Customize your crosshair above.
  2. Tap Copy Valorant Import Code.
  3. Open Valorant on your PC.
  4. Go to Settings → Crosshair.
  5. Find the Import Profile Code button beside your crosshair profiles.
  6. Paste the code and select Import.
  7. Test your new crosshair in The Range.
