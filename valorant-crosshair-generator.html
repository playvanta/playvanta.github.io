How to Import Your Crosshair

  1. Copy the generated crosshair code.
  2. Open Valorant and navigate to Settings → Crosshair.
  3. Choose Import Profile Code.
  4. Paste the code and confirm.
  5. Test the crosshair in the Practice Range.
