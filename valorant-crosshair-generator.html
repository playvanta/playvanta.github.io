How to Generate a Valorant Crosshair Code

PlayVanta's Valorant Crosshair Generator lets you customize your crosshair using sliders for inner line length, thickness, center gap, outer line length and outline thickness. You can also choose a custom color and enable a center dot.

The crosshair preview and profile code update automatically when you change the settings. Once you're satisfied, copy the code and use Valorant's Import Profile Code feature to create a crosshair profile without entering every setting manually.

The preview is an approximation of how the crosshair will look in-game. Valorant's rendering, screen resolution and in-game settings may affect the final appearance.

How to Import a Crosshair Code into Valorant

  1. Open Valorant on your PC.
  2. Go to Settings and select the Crosshair tab.
  3. Find the Import Profile Code button beside the crosshair profile controls.
  4. Paste the full code copied from PlayVanta.
  5. Click Import and select your new crosshair profile.
  6. Check the result in Valorant's Practice Range.
