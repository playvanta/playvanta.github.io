How Does Sensitivity Conversion Work?

Different FPS games use different mouse sensitivity scales. This calculator uses commonly accepted yaw values to preserve approximately the same physical mouse movement for a 360-degree turn.

eDPI is your mouse DPI multiplied by in-game sensitivity. It is useful for comparing settings within the same game, but not directly between games with different yaw values.

Assumes default horizontal sensitivity scaling and no additional mouse acceleration. ADS, scoped sensitivity and special game settings are not included.
