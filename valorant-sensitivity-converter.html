How sensitivity conversion works

The calculator uses standard yaw values to estimate the sensitivity required for the same 360-degree mouse movement. It assumes default mouse input settings and ignores aim-down-sights multipliers, scoped sensitivity and field-of-view differences.

eDPI is your in-game sensitivity multiplied by your mouse DPI. It is most useful when comparing settings within the same game.
